### Como colocar um projeto da Unity no GitHub

1. **Crie um repositório no GitHub**
   Entre no GitHub, clique em **New Repository**, escolha um nome para o projeto e crie o repositório.

2. **Abra o projeto na Unity**
   Abra o projeto que você quer enviar para o GitHub.

3. **Abra o GitHub Desktop**
   No GitHub Desktop, escolha **Add → Add existing repository** e selecione a pasta do seu projeto Unity.

4. **Faça o primeiro commit**
   No GitHub Desktop, coloque uma descrição, como **"Projeto inicial"**, e clique em **Commit to main**.

5. **Envie para o GitHub**
   Clique em **Publish repository** e confirme. O projeto será enviado para o seu repositório no GitHub.
